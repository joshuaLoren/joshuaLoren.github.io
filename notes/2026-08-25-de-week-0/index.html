One request shape doesn't fit every Claude model

Aug 25, 2026 · Dispute Engine

Setting up Dispute Engine, I ran the same classification request against Haiku 4.5 and Opus. Haiku returns a 400 for adaptive thinking and for effort. Code that assumes one request shape for every model breaks the first time you swap models.

The fix is a small function that returns the thinking-related arguments for each model, so call sites stay the same.

The same setup also added Pydantic schemas for DisputeCase and Classification, a versioned prompt, a CLI, and a disk cache for responses. dispute classify fixtures/case_001.json now returns a validated object.
